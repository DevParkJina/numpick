리포트 사용 방법
처음 쓰시는 분들을 위한 단계별 가이드입니다
1
데이터 먼저 조회
상단 필터에서 매체를 선택하고, 기준일 + 월기준으로 분석 기간을 설정한 뒤 조회하세요. 매출 데이터는 조회 결과를 기반으로 자동 계산됩니다.
2
기본 정보 확인
수신(회사명)은 매체 선택 시 자동으로 채워집니다. 필요하면 직접 수정 가능합니다. 발송 년도·월, 담당자 이름도 확인해 주세요.
3
CS 현황 입력
고객 문의 유형별 건수를 입력하세요. 모두 0이면 CS 페이지는 자동으로 생략됩니다.
4
주요 이슈 작성
이번 달 특이 사항이나 이슈를 제목 + 내용으로 추가하세요. 최대 4개까지 추가할 수 있으며, 없으면 비워도 됩니다.
5
업데이트 예정 사항
다음 달에 예정된 변경이나 추가 사항을 입력하세요. 없으면 그냥 두면 됩니다.
6
리포트 생성 → PDF 저장
📄 리포트 미리보기 / 인쇄 버튼 클릭 → 새 창이 열리면 상단의 🖨️ PDF 저장 버튼을 클릭 → 인쇄 창에서 목적지를 PDF로 저장으로 선택하세요.
